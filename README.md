# Organic View

A calm 3D T-shirt configurator

**Owned by [sidd5arth](https://github.com/sidd5arth)**

## Stack

| Three.js | React | TypeScript | Tailwind | GSAP | Vite |
| --- | --- | --- | --- | --- | --- |

Built with **React Three Fiber**, **Drei**, and a Blender-authored T-shirt model.

## Features

- Upload your own **logo** and **full texture**
- Soft **color picker** tuned for organic palettes
- Adjust logo **position** and **size**
- Capture and download a still of your design
- **Print-ready export** — flat pre-stitch cloth layout, front print plate, and isolated graphic
- **Studio AI** — free Pollinations image API to generate graphics and apply as logo or full print
- Calm Airbnb-styled studio UI

### Print export

Use the bottom save control to open **Export studio**:

1. **Flat shirt layout** — unstitched pieces (front, back, sleeves) with logo/texture pixel placement
2. **Front print plate** — front body only, ready for DTG / screen / heat press setup
3. **Print-ready graphic** — isolated artwork PNG
4. **Download all** — pack of the above
5. **3D view snapshot** — the live configurator capture

## Getting started

```bash
npm install
npm run dev
```

```bash
npm run build
npm run preview
```

## Default assets

Swap these files in `public/` (keep the same names):

- Background: `public/bg.png`
- Default logo: `public/logo.png`
- Default texture: `public/full.jpg`
